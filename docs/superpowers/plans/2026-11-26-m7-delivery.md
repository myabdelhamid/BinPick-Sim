# Milestone 7 (Delivery) Plan

**Goal:** what the founder needs to judge and show the work: README, a results report with both planners side by side, a dashboard,
and a 2-minute demo video. Every number in them is read from the delivered benchmark folders (docs/checkpoints/m5, m6), never typed in.

## Deliverables
1. `binpick-dashboard` → `docs/dashboard.html`: one self-contained page (no network), all runs compared, one run at a time in
   detail; tables behind every chart; light and dark. Test: its numbers equal the reports'.
2. `docs/RESULTS.md`: targets, both planners, where it fails, how it got here, what is assumed, how to reproduce, next steps.
3. `scripts/demo_video.py` → `docs/demo.mp4`, under 2 minutes: what the robot sees, the rules planner on seed 1240 (the first
   unused seed, chosen by number), the random baseline on the same bin, the results, the limits.
4. README rewritten around the results.

## Review Focus
1. Any number in README, RESULTS, dashboard or video that differs from the benchmark files.
2. Any wording that makes the results look better than they are (blind vs rerun, ranges, assumptions).
3. The dashboard with other runs (one planner, a failed bin, no successes).
