# Milestone 1 (Project Setup + Scene) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Set up the project, and produce a seeded MuJoCo cell (Panda + 44 mm cup, bin on a shaker, 20 settled parts, 5×4 tray, bin and tray cameras) that saves RGB and depth images with one command.

**Architecture:** One package, `binpick`. `config.py` loads a single YAML into frozen dataclasses. `sim/parts.py` samples part specs (pure NumPy). `sim/scene.py` builds the world with `mujoco.MjSpec` around the vendored Menagerie Panda. `sim/settle.py` drops parts one at a time. `sim/camera.py` renders headless. `motion/ik.py` (mink) proves reachability. `cli.py` writes the outputs.

**Tech Stack:** Python 3.12 (uv), mujoco ≥ 3.2, mink, numpy, open3d (installed now, used in M3), pyyaml, pillow, imageio, pytest, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-23-binpick-sim-design.md`

## Global Constraints

- Python pinned to 3.12 (`.python-version` + `requires-python = ">=3.12,<3.13"`). Open3D has no 3.13 arm64 wheels.
- SI units everywhere, YAML included (m, kg, s).
- All randomness via `numpy.random.default_rng`. Parts use stream `default_rng([seed, 0])`; drops use stream `default_rng([seed, 1])`.
- All tunable values live in `configs/default.yaml`. No magic numbers in modules beyond physical constants.
- Boxes: 15, footprint 0.045–0.110 m per side, height 0.020–0.070 m. Cylinders: 5, diameter 0.040–0.080 m, length 0.040–0.110 m.
- Materials: plastic p=0.6, ρ=1200; aluminium p=0.3, ρ=2700; steel p=0.1, ρ=7850 (kg/m³). Mass ∈ [0.05, 2.5] kg, enforced by resampling dims with the same material.
- Cup: outer diameter 0.044 m, length 0.020 m, rated hold 3.0 kg. Adhesion actuator, ctrl range [0, 1].
- Bin inner 0.400 × 0.300 × 0.200 m, wall 0.010 m, on x/y shaker slide joints with position actuators.
- Tray: 4 rows × 5 cols, slot 0.120 m.
- Tests and CLI run headless. Only `binpick.view` needs `mjpython`.
- Panda assets vendored with their Apache-2.0 LICENSE, plus `VENDORED.md` recording the source commit.
- Commits: conventional prefixes, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. A seed where a part keeps escaping the bin. Settling must stop after `settle.max_redrops` and raise `SettleError` with the part id, not loop forever. (Test in Task 5.)
2. Headless rendering. Must work on macOS with no window and on Ubuntu CI with `MUJOCO_GL=egl`. (CI env in Task 1, render test in Task 6.)
3. Bad config values (min > max, material probabilities not summing to 1, mass_min ≥ mass_max). `load_config` raises `ValueError` naming the field. (Test in Task 1.)
4. Running `binpick-scene` twice for the same seed overwrites cleanly and produces identical `parts.json`. (Test in Task 6.)
5. Seed 0 and a large seed (2**31 − 1) both work. (Test in Task 2.)

### Task 5: Drop and settle

**Files:**
- Create: `src/binpick/sim/settle.py`
- Test: `tests/test_settle.py`

**Interfaces:**
- Consumes: `Scene`
- Produces:
  - `PartPose(id: int, pos: np.ndarray, quat: np.ndarray)` (quat is wxyz)
  - `settle_parts(scene: Scene, rng: np.random.Generator) -> list[PartPose]`. For each part in id order: random x/y inside `bin_inner_bounds` inset by `settle.inset`, z = rim + `drop_height_above_rim`, uniform random quaternion, zero velocity. Step until every placed part satisfies `lin_tol` and `ang_tol`, or until `drop_timeout_s`. A part whose center ends outside the inner bounds is re-dropped (same rng stream). More than `max_redrops` → `SettleError(part_id)`.
  - `class SettleError(RuntimeError)` with attribute `part_id: int`
  - `max_penetration(scene: Scene) -> float` (largest negative `contact.dist` among contacts involving a part)
  - `make_settled_scene(cfg: Config, seed: int) -> tuple[Scene, list[PartPose]]`, the convenience wrapper used by the CLI and tests (streams per Global Constraints)

- [ ] **Step 1: Write the failing tests**
